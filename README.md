\## 📌 Описание проекта

Данный проект представляет собой десктопное приложение для ведения личной коллекции рецептов коктейлей. Программа позволяет добавлять новые рецепты, указывать их ингредиенты и крепость, а также удалять записи из списка. 



Проект разрабатывается поэтапно в рамках курса «Кроссплатформенная разработка» и будет дополняться новыми функциями (база данных, графики, работа с сетью) по мере прохождения соответствующих лабораторных работ.



\*\*Ключевые сущности:\*\*

\*   Коктейль (Название)

\*   Ингредиенты

\*   Крепость (в %)

\## 🛠️ Инструкция по сборке и запуску

Для сборки и запуска проекта вам потребуется установленный \*\*Qt Creator\*\* (версия 6.x) и компилятор (например, MinGW или MSVC).



1\. Откройте \*\*Qt Creator\*\*.

2\. В меню выберите \*\*Файл -> Открыть файл или проект\*\*.

3\. Выберите файл `cocktail-collection.pro` из папки с проектом.

4\. Выберите нужный Kit (компилятор) и нажмите \*\*«Настроить проект»\*\*.

5\. Нажмите \*\*Собрать\*\* (Ctrl+B), а затем \*\*Запустить\*\* (Ctrl+R).

\## 📝 Текущий функционал

1\.  \*\*Просмотр списка:\*\* При запуске отображаются тестовые записи (Мохито, Маргарита).

2\.  \*\*Добавление:\*\* Нажатие на кнопку «Добавить» (на панели или в меню) вызывает диалоговые окна для ввода названия, ингредиентов и крепости. Новый коктейль сразу появляется в списке.

3\.  \*\*Удаление:\*\* Выберите коктейль в списке и нажмите «Удалить». Запись будет удалена.

4\.  \*\*Меню «Справка»:\*\* Содержит информацию о проекте и авторе.
