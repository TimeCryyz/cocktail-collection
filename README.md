**Технология:** Qt 6 (C++), qmake

## Описание проекта

Данный проект представляет собой десктопное приложение для ведения личной коллекции рецептов коктейлей. Программа позволяет добавлять новые рецепты, указывать их ингредиенты и крепость, а также удалять записи из списка.

Проект разрабатывается поэтапно в рамках дисциплины «Основы кроссплатформенного программирования» и будет дополняться новыми функциями (база данных, работа с сетью) по мере прохождения соответствующих лабораторных работ.

**Ключевые сущности:**
*   Коктейль (Название)
*   Ингредиенты
*   Крепость (в %)

## Структура проекта

Проект организован согласно стандартам разработки на C++:
*   `src/` — исходный код главного окна, точки входа и кастомных виджетов (`main.cpp`, `mainwindow.cpp/h`, `strengthchartwidget.cpp/h`).
*   `models/` — классы для работы с данными (`cocktailmodel.cpp/h`).
*   `cocktail-collection.pro` — файл конфигурации сборки qmake.

*   `README.md` — описание проекта.

## Инструкция по сборке и запуску

Для сборки и запуска проекта вам потребуется установленный Qt Creator (версия 6.x) и компилятор (например, MinGW или MSVC).

1. Откройте Qt Creator.
2. В меню выберите Файл -> Открыть файл или проект.
3. Выберите файл `cocktail-collection.pro` из папки с проектом.
4. Выберите нужный Kit (компилятор) и нажмите «Настроить проект».
5. Нажмите Собрать (Ctrl+B), а затем Запустить (Ctrl+R).

## Текущий функционал

1.  **Список и добавление:** Отображение списка коктейлей (Мохито, Маргарита). Нажатие на кнопку «Добавить» вызывает диалоговые окна для ввода названия, ингредиентов и крепости.
2.  **Удаление:** Выберите коктейль в списке и нажмите «Удалить». Запись будет удалена. Также доступна кнопка «Снять выделение».
3.  **Диаграмма крепости:** В нижней части окна отображается график (виджет `StrengthChartWidget`), который рисует столбики крепости для каждого коктейля.
4.  **Анимация (QTimer):** График автоматически меняет цвет каждые 2 секунды. Мигание можно остановить или запустить снова с помощью кнопки «Стоп/Старт мигания».
5.  **Смена цвета графика:** Кнопка «Сменить цвет графика» позволяет вручную переключить цветовую схему диаграммы.
6.  **Меню «Справка»:** Содержит информацию о проекте и авторе.
